# Python_NEST_tutorial

This repository contains 3 parts:
1. An introduction to PyNEST
2. Two examples of NEST Desktop. Directly download these two files and import them into NEST Desktop.
3. A reduced network model to reproduce some important findings of the [paper](https://doi.org/10.1101/2022.07.18.500396).


You need:\
Python 3\
NEST 3
